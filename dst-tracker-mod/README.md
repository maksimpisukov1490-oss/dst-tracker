# DST Compendium Sync — мод для DST

Серверный мод для Don't Starve Together: слушает смерти боссов и пишет снимок
прогресса в JSON-файл. Сайт «Компендиум выжившего» забирает этот файл через
`tools/bridge.py` и добавляет победы в текущий забег.

- **Сервер ведёт учёт.** Клиентам для синхронизации ничего ставить не нужно.
- **Кнопка в паузе.** Если мод стоит и на клиенте (включая хоста), в меню паузы
  появляется **«Компендиум»** — экран прогресса мира.
- **Без бэкенда и без сети.** Мод пишет файл на диск, мост читает его локально.
- Работает и в мире, который хостит игрок, и на выделенном сервере.

## Установка

Автоматически (Steam-библиотека находится сама):

```bash
python3 tools/install_mod.py
```

Вручную: скопируй папку `dst-tracker-mod` в
`<Don't Starve Together>/mods/dst-tracker-sync` так, чтобы внутри лежал
`modinfo.lua`.

Затем в игре: **Моды → серверные моды → DST Compendium Sync → включить**.
Для мира с пещерами включи мод на обоих шардах (лес и пещеры). Чтобы видеть
кнопку «Компендиум» в паузе, мод должен быть включён и на клиенте (у хоста —
автоматически; гостям с модом — тоже).

## Как включить прогресс

Сайт умеет читать JSON мода **напрямую**: кнопка **«Файл»** в шапке, выбрать
папку `DoNotStarveTogether` (Chrome/Edge). Мост в этом случае не нужен.

Если браузер не поддерживает прямое чтение или мод пишет в `CloudSaves/*.zip`,
используй мост:

1. Запусти мост:

   ```bash
   python3 tools/bridge.py
   ```

2. Открой сайт и нажми кнопку **«Игра»** в шапке. Она станет зелёной.
3. Заходи в мир и бей боссов. Мост опрашивается раз в 5 секунд, победы
   добавляются в забег этого мира. Прогресс только дополняется: локальные
   отметки никогда не стираются.
4. В игре открой паузу и нажми **«Компендиум»** — там список боссов, победы,
   метки и навыки. Экран обновляется по запросу к серверу.

## Куда пишется файл

Мод пробует пути по очереди и пишет в первый доступный:

```
Windows / Proton:  Documents\Klei\DoNotStarveTogether\dst-tracker-sync.json
Linux:             ~/.klei/DoNotStarveTogether/dst-tracker-sync.json
Резерв:            <игра>/mods/dst-tracker-sync.json
```

Для пещер — те же имена с суффиксом `-caves.json`.

Переопределить базу можно переменной окружения `DST_TRACKER_SYNC` (путь без
`.json`). Если запись через `io` недоступна, мод падает в резервное хранилище
сейва (`TheSim:SetPersistentString`).

Мост сам ищет файл в `~/.klei`, `~/Documents/Klei` и Proton-префиксах Steam
(`steamapps/compatdata/322330/...`), затем в папке `mods` игры. Если файлов
несколько, берётся самый свежий мир; лес и пещеры объединяются: счётчики — по
максимуму, игроки и уровни фигур — по объединению.

**Важно:** в песочнице DST у мода нет `io`/`os.getenv`, поэтому обычная запись
файла часто недоступна. Тогда мод пишет через `TheSim:SetPersistentString` в
штатное хранилище игры:

```
<userid>/client_save/dst_tracker_sync_forest
<userid>/client_save/dst_tracker_sync_caves
```

На клиентском хосте игра может хранить их внутри облачного сохранения:
`CloudSaves/<hash>/Master.zip` и `Caves.zip`, запись `save/dst_tracker_sync_*`.
Мост читает и распакованные файлы, и эти архивы; заголовок `KLEI`
отбрасывается. Если у тебя не подключается — проверь, что после входа в мир
обновился `Master.zip` или появился `dst_tracker_sync_*` в `client_save`.

## Экран-компендиум в паузе

Кнопка **«Компендиум»** добавляется в меню паузы. Это не просто список, а
мини-версия сайта:

- шапка мира: название, день, сезон, персонаж;
- полоса прогресса и счётчики: победы `N / 36`, метки `M / 51`, навыки и
  озарение;
- вкладки категорий: все, сезонные гиганты, рейдовые, твари разломов,
  мини-боссы;
- прокручиваемый список боссов с иконками из игрового скрапбука, галочкой,
  именем, числом побед и днём;
- панель выбранного босса: иконка, категория, HP, урон, планарный урон,
  описание и добыча.

Данные прогресса приходят с сервера по RPC, статичные описания и иконки —
из сгенерированного `scripts/boss_data.lua` (из данных сайта, сам сайт не
меняется).

## Что мод сообщает о мире

Кроме убийств, в файл попадает:

- `world.name` — название мира (`TheNet:GetServerName()`, то есть `cluster_name`);
- `world.char` — префаб персонажа хоста (на выделенном сервере — первого игрока);
- `world.player` — ник этого игрока;
- `world.players` — кто был в мире;
- `world.day`, `world.season`, `world.phase`.

Ещё мод присылает `skills`: персонажа, список изученных навыков, озарение и
опыт. Сайт показывает вкладку «Навыки» для персонажей с деревом и подсвечивает
изученные узлы. Снимок обновляется сразу после изучения/сброса навыка и при
получении озарения.

Сайт по этим данным создаёт забег: имя мира, персонаж, ник и голова. При смене
мира заводится отдельный забег.

## Ретроактивность

Мод восстанавливает то, что мир реально хранит:

- задания отшельницы (`friendlytasks`);
- флаги Вагстафа (`sparkark`, `pearlmap`, `pearlmove`, `turfed`, `state`);
- теги мира: разломы, архивы, небесная сфера, ключи;
- постройки: алтари, Таинственная энергия, сифонатор, врата, скелет;
- предметы: `dreadstone`, `vault_key`, `shadowheart`, дары королевы и т.д.;
- **число убийств Небесного защитника** — точно, через
  `moonstormmanager:GetCelestialChampionsKilled()`; если он убит, вся цепочка
  Лунного острова и алтарей тоже считается пройденной;
- **Древний страж** — по тегу `ATRIUM_KEY_FOUND` или Древнему ключу: ключ
  выпадает только со стража.

Чего восстановить нельзя:

- даты и дни прошлых убийств;
- точные счётчики большинства боссов;
- исследование карты (оно хранится на клиенте, не на сервере);
- события, которые мир не запоминает (разобранная свалка Вагстафа и т.п.).

Опционально можно добавить «ретро по добыче»: уникальные трофеи (глаз
Циклопа-оленя, чешуя Драконьей мухи, корона Пчелиной королевы, шерсть
Эвекуса и т.д.) → вероятная победа. Это неточно: предмет мог быть подарен,
найден в сундуке или остаться с другого мира. Сейчас этот режим не включён.

## Что считается победой

- **Только новые смерти.** Мод не сканирует мир и не знает, кого убили до его
  включения. Заходишь в давно пройденный мир — счётчик пуст; засчитываются
  только смерти, случившиеся при включённом моде.
- **Первое подключение сайта — точка отсчёта.** Уже накопленные за сессию
  смерти не переливаются в забег: сайт запоминает текущие числа и добавляет
  только то, что произойдёт дальше.
- Одна смерть префаба = одна победа. Серия смертей в окне «склейки» (по
  умолчанию 15 секунд) считается одной победой: это нужно для теневых шахмат,
  близнецов и фаз.
- Счётчики мода живут в рамках сессии сервера. После перезапуска они начинаются
  с нуля, но в файле есть `session`, поэтому сайт понимает, что это новая
  сессия, и продолжает счёт без потерь и дублей.
- У теневых шахмат дополнительно записываются уровни фигур
  (`levels.knight/bishop/rook`), и сайт выставляет их в карточке.
- У каждой победы сохраняется **день мира** (`day`) на момент смерти, а в
  `world.day` — текущий день. Сайт показывает день в карточке, хронике и записи,
  а текущий день забега — в шапке.
- Древний топливопряд слушается как `stalker_atrium`, Небесный защитник — только
  финальная фаза `alterguardian_phase3`.

## Отметки вкладки «Прогресс»

Мод отмечает не только боссов, но и шаги прогресса. Что и как проверяется:

| Ветка | Как определяется |
|---|---|
| Отшельница | 15 заданий `friendlevels.friendlytasks[ID].complete` |
| Вагстаф | флаги `moonstormmanager` и `wagpunk_arena_manager` (`sparkark`, `pearlmap`, `pearlmove`, `turfed`, `state`), предметы, счётчик полных клеток гештальтов, смерть Ревенанта |
| Чарли | предметы (`dreadstone`, `vault_key`, `shadowheart`, дары королевы), теги мира, спавн и смерть королевы/мерзости |
| Небесный защитник | полная сборка алтарей (`_stage`, ремонт святилища), `moon_altar_link`, `moon_device`, спавн `alterguardian_phase1` |
| Древний топливопряд | активация врат (`atrium_gate_activatedfx`), `fossil_stalker`, `stalker_atrium`, предметы и теги |
| Вехи | теги `LUNAR_RIFTS_ACTIVE`, `SHADOW_RIFTS_ACTIVE`, `ARCHIVES_ENERGIZED`, `CELESTIAL_ORB_FOUND`, порталы разломов, гломмер, близость к Лунному острову/руинам/Атриуму |

Ограничения:

- **Ретроактивно ничего не берётся.** Если событие случилось до включения мода
  и мир его не хранит (например, разобрали свалку Вагстафа), отметка не
  появится.
- Часть отметок — приближение по близости: Лунный остров (`moon_fissure`),
  руины (статуи, реликвии, светильники), Атриум (`atrium_gate`).
- `wag_gestalt` считается консервативно: две полные клетки по 3 гештальта.
- Если сомневаешься, отметь шаг вручную на сайте — мод только дополняет.

Полная карта slug → префаб лежит в `scripts/boss_map.lua`; имена сверены с
`scripts/prefabs` установленной игры.

## Настройки мода

В меню модов:

- **Склейка серии смертей** — 5/10/15/30 секунд.
- **Запись состояния** — 15/30/60 секунд (день, сезон, игроки).

## Если не работает

- Кнопка «Игра» красная → мост не запущен или другой порт:
  `python3 tools/bridge.py --port 8787`.
- Мост отвечает, но файла нет → мод не включён в мире или мир ещё не загружен.
- Файл есть, но не обновляется → проверь лог игры: мод печатает
  `[dst-tracker] синхронизация пишется в ...` при первой удачной записи.
- На выделенном сервере `HOME` может отличаться: задай `DST_TRACKER_SYNC`
  в окружении сервера.
